**HOW TO START USING**
- Start a new Claude session in <VAULT path>; that folder has everything loaded.

**HOW TO SEE SKILLS AND AGENTS**
- Type /rbx-list in that session, or / then rbx-. Make your own skill: ask Claude to use /rbx-new-skill.

**THE TWO MODS (ALREADY INSTALLED)**
- Type /reload-plugins once; they run in the vault folder only. Remove: /plugin, or the installer's --no-mods.

**HOW TO MAKE A GAME IDEA**
- /rbx-ideas finds one fresh idea (reply another, build it or plan); /rbx-idea-creator starts from yours.

**HOW TO BUILD A GAME**
- /rbx-workflow builds a game: design pack first (style, UI, map, plan; Figma if connected), no code before you approve.

**HOW TO UPDATE**
- Type /rbx-update (works from any session, even after you move the vault folder).

**NOT SURE WHICH SKILL?**
- Just describe what you want; Claude offers the right skill and you reply yes.

More details: MANUAL-READ.md in the vault folder (or https://vault-hhmi60uo.netlify.app/manual).
