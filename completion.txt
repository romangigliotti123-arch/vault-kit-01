The Roblox Dev Mastery Vault is now set up.
Where it lives: <VAULT path> (Claude kit in ~/.claude, Roblox assets in <VAULT path>/Assets).

Switch it on (the vault is OFF in every Claude session until you do this)
- In your Roblox project folder start Claude and type /load-rbxdev-vault : Roblox dev mode (vault skills, agents, art-direction, placement and visual-QA rules, reference images, learn step). /unload-rbxdev-vault turns it off again. Always available: /load-rbxdev-vault /unload-rbxdev-vault /update-rbxdev-vault /update-check-rbxdev-vault /uninstall-rbxdev-vault.
Make a game (after /load-rbxdev-vault)
- /game-dev-workflow : the full flow. Give an idea (or none); it elaborates it from the vault, rates it 1.00-10.00, writes a build plan, asks "Ready to build?", then a head manager builds it and playtests.
- /make-roblox-game : one sentence in, a Rojo/Luau game project out (also: say "make me a Roblox game: <idea>").
Side skills (each also works alone)
- /game-dev-rate : rate an idea 1.00-10.00 on 12 weighted criteria.
- /game-dev-plan : turn a rated idea into game-plan.md (systems, milestones, agents, models, budget).
- /game-dev-ads : ads plan for a game. /game-dev-update : update and live-ops plan.
- /game-dev-playtest : playtest and bug report. /game-dev-thumbnail : icon, thumbnails and screenshots.
- /game-dev-placement-qa : placement gate; every model created, inserted or moved is measured in Studio (pivot, size, grounded, upright, facing, overlap, anchoring, connections), auto-fixed and re-verified; a full-map scan must pass before a game is called done. /game-dev-art-direction : art bible before building. /game-dev-visual-qa : screenshot-based visual gate.
Research
- /deep-topic-research-rbxdev-vault : deep multi-source research on any topic, saved to My Research/.
Manager
- /manager-mode-rbxdev-vault : this session delegates to right-sized worker agents (haiku/sonnet/opus).
Vault
- /update-rbxdev-vault (safe update, keeps My Research), /update-clean-rbxdev-vault (exact copy of the main vault), /light-mode-on-rbxdev-vault and /light-mode-off-rbxdev-vault (hide or show the big supporting folders in Obsidian). /low-usage-mode-rbxdev-vault (keeps Claude in low usage mode: cheapest model, short replies, small tool output; /low-usage-mode-rbxdev-vault off ends it). /learn-rbxdev-vault (record a verified finding; curated notes land in learned/ and are checked first).

How it works: the Roblox knowledge base in this vault (sourced creator and official-docs notes, benchmarks, case studies) is the evidence. /game-dev-workflow turns your idea into a researched design, rates it, plans it with agents and models, and only after you say "Ready to build?" does a head manager build the Rojo/Luau project and playtest it. Nothing is published to Roblox and no Robux are spent. Update the vault any time with /update-rbxdev-vault (automatic updates at logon are optional and can be added on request). Nothing is loaded into your other Claude sessions: type /load-rbxdev-vault in the project folder where you want it.
