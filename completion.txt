The Roblox Dev Mastery Vault is now set up.
Where it lives: <VAULT path> (Claude kit in ~/.claude, Roblox assets in <VAULT path>/Assets).

Switch it on (the vault is OFF in every Claude session until you do this)
- In your Roblox project folder start Claude and type /rbx-load : Roblox dev mode (vault skills, agents, art-direction, placement, lighting and visual-QA rules, reference images, learn step). /rbx-unload turns it off again. Always available: /rbx-load /rbx-unload /rbx-update /rbx-check /rbx-uninstall.
Make a game (after /rbx-load)
- /rbx-workflow : the full flow. Give an idea (or none); it elaborates it from the vault, rates it 1.00-10.00, writes a build plan, asks "Ready to build?", then a head manager builds it and playtests.
- /rbx-make : one sentence in, a Rojo/Luau game project out (also: say "make me a Roblox game: <idea>").
Side skills (each also works alone)
- /rbx-rate : rate an idea 1.00-10.00 on 12 weighted criteria.
- /rbx-plan : turn a rated idea into game-plan.md (systems, milestones, agents, models, budget).
- /rbx-ads : ads plan for a game. /rbx-game-update : update and live-ops plan.
- /rbx-playtest : playtest and bug report. /rbx-thumbnail : icon, thumbnails and screenshots, scored with a click-psychology rubric (thumb_score.py; results ledger thumb_record.py).
- /rbx-placement : placement gate; every model created, inserted or moved is measured in Studio (pivot, size, grounded, upright, facing, overlap, anchoring, connections), auto-fixed and re-verified; a full-map scan must pass before a game is called done. /rbx-lighting : lighting and atmosphere gate; the genre's preset (Future lighting, Atmosphere, Sky, Bloom, ColorCorrection, SunRays, mobile-safe variant) is applied early and a 12-check scan (not default Roblox, sane effects, brightness, shadows, fog, interiors, budget) must pass before a game is called done. /rbx-art : art bible before building. /rbx-visual : screenshot-based visual gate.
- /rbx-tune : bounded metric loop for balance, optimise and polish: one number, a read-only evaluator, one change per experiment, keep only strict improvements, ledger in Games/<slug>/tune/ checked by tune_check.py.
- /rbx-bench : scorecard of a game across every gate (0-100, history, compare), 3 standard test games, and what load mode costs a session.
Research
- /rbx-research : deep multi-source research on any topic, saved to My Research/.
Manager
- /rbx-manager : this session delegates to right-sized worker agents (haiku/sonnet/opus).
Vault
- /rbx-update (safe update, keeps My Research), /rbx-clean (exact copy of the main vault), /rbx-light-on and /rbx-light-off (hide or show the big supporting folders in Obsidian). /rbx-low-usage (keeps Claude in low usage mode: cheapest model, short replies, small tool output; /rbx-low-usage off ends it). /rbx-learn (record a verified finding; curated notes land in learned/ and are checked first).
Roblox specialist skills (Claude picks them, or call by name)

How it works: the Roblox knowledge base in this vault (sourced creator and official-docs notes, benchmarks, case studies) is the evidence. /rbx-workflow turns your idea into a researched design, rates it, plans it with agents and models, and only after you say "Ready to build?" does a head manager build the Rojo/Luau project and playtest it. Nothing is published to Roblox and no Robux are spent. Update the vault any time with /rbx-update (automatic updates at logon are optional and can be added on request). Nothing is loaded into your other Claude sessions: type /rbx-load in the project folder where you want it.
Optional question (no answer means no): Manual UI mockups: want Claude to give you prompts, reference images and steps to make UI mockups yourself with Nano Banana 2.1 on the Gemini website? Default is no: Claude designs the UI itself first. Change any time with /rbx-mockup on|off.
