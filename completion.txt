The Roblox Dev Mastery Vault is now set up.
Where it lives: <VAULT path> (Claude kit in ~/.claude, Roblox assets in <VAULT path>/Assets).

Make a game
- /game-dev-workflow : the full flow. Give an idea (or none); it elaborates it from the vault, rates it 1.00-10.00, writes a build plan, asks "Ready to build?", then a head manager builds it and playtests.
- /make-roblox-game : one sentence in, a Rojo/Luau game project out (also: say "make me a Roblox game: <idea>").
Side skills (each also works alone)
- /game-dev-rate : rate an idea 1.00-10.00 on 12 weighted criteria.
- /game-dev-plan : turn a rated idea into game-plan.md (systems, milestones, agents, models, budget).
- /game-dev-ads : ads plan for a game. /game-dev-update : update and live-ops plan.
- /game-dev-playtest : playtest and bug report. /game-dev-thumbnail : icon, thumbnails and screenshots.
Research
- /deep-topic-research : deep multi-source research on any topic, saved to My Research/.
Manager
- /manager-mode : this session delegates to right-sized worker agents (haiku/sonnet/opus).
Vault
- /vault-update (safe update, keeps My Research), /vault-update-clean (exact copy of the main vault), /light-mode-on and /light-mode-off (hide or show the big supporting folders in Obsidian). /low-usage-mode (keeps Claude in low usage mode: cheapest model, short replies, small tool output; /low-usage-mode off ends it). /vault-learn (record a verified finding; curated notes land in learned/ and are checked first).

How it works: the Roblox knowledge base in this vault (sourced creator and official-docs notes, benchmarks, case studies) is the evidence. /game-dev-workflow turns your idea into a researched design, rates it, plans it with agents and models, and only after you say "Ready to build?" does a head manager build the Rojo/Luau project and playtest it. Nothing is published to Roblox and no Robux are spent. Update the vault any time with /vault-update (automatic updates at logon are optional and can be added on request); start a new Claude session (or run /agents) to load the commands.
